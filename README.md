RabotaHub - Платформа за Огласи
Модерна, двојазична платформа за огласи за кандидати и работодавци во Македонија. Изградена со Django, овозможува на кандидатите да наоѓаат можности и на работодавците да објавуваат и управуваат со огласи.

Функции
Пребарување на огласи: Пребарувајте и филтрирајте огласи по категорија, локација и плата
Лесни апликации: Комплексни формулари со качување CV и прашувања за селекција
Систем за пораки: Директна комуникација помеѓу кандидатите и работодавците
Кориснички профили: Налози базирани на улоги (работодавец/барател) со статистика
**Двојазична поддршка: Комплетен превод на англиски и македонски јазик
Модерен UI: Чист, респонзивен дизајн инспириран од големи платформи за огласи

Технологии
Backend: Django 6.0.3 (Python)
База на податоци: SQLite
Frontend: HTML5, CSS3, Bootstrap 5
Автентикација: Django auth со прилагодени профили

Инсталација
pip install django
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

Користење
Регистрирајте се како "Барател на работа" или "Работодавец"
Пребарувајте/Објавувајте огласи со напредни филтри
Аплицирајте со детални формулари вклучувајќи качување CV
Порачувајте директно со кандидатите/работодавците
Преклучувајте помеѓу EN/MK јазици

Цел
Кандидати и работодавци во Македонија кои бараат модерна платформа за вработување.
